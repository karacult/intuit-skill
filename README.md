# intuit

Explain complex concepts to an intelligent adult non-specialist. Build a correct
mental model quickly, expose the important practical realities, then stop.

An [agent skill](https://skills.sh) for AI agents: TL;DR, a mental model, a reality
check, and next questions — deeper layers only when requested.

[![skills.sh](https://skills.sh/b/karacult/intuit-skill)](https://skills.sh/karacult/intuit-skill)

## Install

```bash
npx skills add karacult/intuit-skill --skill intuit
```
